

1. AWS - надає послуги IaaS (Infrastructure as a Service)

основні сервіси які треба знати:
- EC2 - віртуальні машини
- S3 - об'єктне сховище (існує що замінити потребу крутити власний веб-сервер для роздачі файлів, зберігання бекапів, статичного контенту сайту. ) 
- RDS - керовані реляційні бази даних (існує що замінити потребу створювати кластер з віртуальних машин, розгортати на них базу даних та підтримувати її власноруч в робочому стані)
- VPC - віртуальна приватна хмара (існує що замінити потребу крутити власний веб-сервер для роздачі файлів, зберігання бекапів, статичного контенту сайту. ) 
- IAM - управління доступом (існує що замінити потребу крутити власний веб-сервер для роздачі файлів, зберігання бекапів, статичного контенту сайту. )
